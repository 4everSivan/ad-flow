# 任务卡建卡流程

**created** 2026-11-22 · **last-change** 2026-11-22 · **status** baseline

## T 卡建卡前的对抗性讨论

<!-- @topic: TaskCardCreation -->

用户提出按 T 卡推进后，Agent 根据项目内的提示词与用户至少讨论一轮，主动检查提案可能遗漏的假设、边界或失败场景。提问方式取决于具体提案。讨论结果用于设计、任务拆解、依赖和验收定义，随后运行 A6 生成只读建卡计划。

目标项目的 `AGENTS.md` 在 T 卡入口触发这一步，提示词随任务目录 README 一起安装和升级。本仓的任务 SOP 指向[同一份提示词模板](../../../templates/docs/task/README.md.tpl#grill-me)。C 卡继续按变更 SOP 建卡，T 卡交付后的人工验收继续以实测证据为依据。

## 验收

- 本仓和安装后的 T 卡入口都能在 A6 前定位到提示词。
- 安装后的提示词要求至少讨论一轮，提问方式可随提案调整。
- C 卡入口、A6 和安装包契约通过现有回归检查。
